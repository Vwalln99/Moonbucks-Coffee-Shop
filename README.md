# Moonbucks Coffee Shop

**Eine interaktive Website, auf der du Bestellungen aufgeben und ändern, das Team kennenlernen oder eine Nachricht hinterlassen kannst.**

---

## 📖 Überblick

Die *Moonbucks Coffee Shop*-Website wurde mit **JavaScript**, **Webpack**, **HTML** und **CSS** entwickelt, um ein modernes und benutzerfreundliches Erlebnis zu bieten. Die Plattform ermöglicht es Nutzer:innen, Bestellungen aufzugeben oder zu ändern, das Team hinter Moonbucks kennenzulernen und direkt Kontakt aufzunehmen.

Die wichtigsten Funktionen:

- **Bestellungen verwalten:** Aufgeben und Ändern von Bestellungen.  
- **Team kennenlernen:** Vorstellung des Teams hinter Moonbucks.  
- **Kontakt aufnehmen:** Möglichkeit, Nachrichten direkt über die Website zu senden.

Jetzt besuchen: [Moonbucks Coffee Shop](https://vwalln99.github.io/Moonbucks-Coffee-Shop/)

## 🚀 Installation und Einrichtung

### Voraussetzungen
- Installiere [Node.js](https://nodejs.org/) (empfohlene Version).  
- Installiere [npm](https://www.npmjs.com/) oder [yarn](https://yarnpkg.com/).  
- Installiere eine IDE wie [Visual Studio Code](https://code.visualstudio.com/).  

### Schritte zum Starten der App
1. **Repository klonen:**  
   Klone das Repository in dein lokales Verzeichnis:  
   ```bash
   git clone https://github.com/Vwalln99/Moonbucks-Coffee-Shop.git
   ```

2. **Zum Projektverzeichnis wechseln:**  
   ```bash
   cd Moonbucks-Coffee-Shop
   ```

3. **Abhängigkeiten installieren:**  
   Mit npm:  
   ```bash
   npm install
   ```
   Oder mit yarn:  
   ```bash
   yarn install
   ```

4. **Entwicklungsserver starten:**  
   Mit npm:  
   ```bash
   npm run start
   ```
   Oder mit yarn:  
   ```bash
   yarn start
   ```

5. **App im Browser öffnen:**  
   Gehe zu `http://localhost:8080`, um die Website auf deinem lokalen Server zu sehen.
